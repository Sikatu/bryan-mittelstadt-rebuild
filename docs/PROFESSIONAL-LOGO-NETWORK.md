# Universal Logo Placement System

## Professional logo section

Every rendered portfolio page uses the same four professional marks:

1. SAG-AFTRA
2. Actors' Equity Association
3. CESD Talent Agency
4. Eris Talent Agency

The section is mounted globally before the footer and is also displayed
on LMNTL STUDIOS because the current placement rule applies to every page.

The marks are presentation-only. No union or agency destination is guessed.
